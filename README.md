# Pulse Quest

App sportive personnelle, pensée pour l’iPhone et prête pour GitHub Pages.

## Publication sur GitHub Pages
1. Crée un dépôt GitHub. Avec GitHub Pages standard, l’URL du site sera publique.
2. Ajoute le contenu de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, active le déploiement depuis la branche principale et le dossier `/ (root)`.
4. Ouvre l’URL sur l’iPhone dans Safari, puis choisis **Partager → Sur l’écran d’accueil**.

Les données d’entraînement restent dans le stockage local du navigateur. Elles ne sont pas envoyées à GitHub. Effacer les données du navigateur peut supprimer ces relevés ; utilise **Réglages → Exporter mes données** pour en garder une copie.

## Inclus
- Parcours de progression inspiré d’un jeu : XP, niveaux, série et étapes.
- Programme du 12 octobre au 31 décembre 2026 : trois séances haut du corps, deux courses progressives, cinq séances abdos et étirements quotidiens.
- Séances avec consignes, séries, photos et chrono.
- Historique local du poids, des tractions et des distances courues.
- Export/import JSON, installation comme PWA et consultation hors ligne après la première visite.
- Rappels optionnels pendant que la page reste ouverte. iOS peut suspendre les notifications web lorsque l’app est fermée.

## Confidentialité
Aucun compte, serveur, analyseur ou suivi publicitaire n’est inclus. Les photos sont générées pour cette app et intégrées aux fichiers du site.
